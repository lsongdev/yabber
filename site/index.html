02 / PLAIN YAML. THAT’S IT.

A domain.
A destination.
You’re home.

No elaborate setup to get in your way. Start with a few lines, then add routes and policies as your setup grows.

Explore the full configuration ↗

With ACME enabled, point your domain to the gateway and make port 80 reachable for certificate validation.

≡ config.yaml
# Your domain. Your local app.
tls:
  acme:
    email: hello@example.com

sites:
  - hosts: [app.example.com]
    proxy: http://127.0.0.1:3000
Automatic HTTPS → your app on port 3000

03 / MAKE YOURSELF AT HOME

Up and routing.

Install on OpenWrt or a systemd host, add your first service, and open the door.

Browse release downloads ↗
1

Meet your new gateway.

The installer selects your platform, verifies the release checksum, and installs the service.

curl -fsSL https://github.com/lsongdev/yabber/releases/latest/download/install.sh | sh

Prefer Go? go install github.com/lsongdev/yabber/cmd/yabber@latest

2

Give your service an address.

Use an example above to edit your configuration. The first install creates a starter file and leaves the service stopped.

systemd /var/lib/yabber/config.yamlOpenWrt /etc/yabber/config.yaml

On OpenWrt, move LuCI off ports 80 and 443 before starting Yabber. Installation notes ↗

3

Let it in.

Start your gateway. Yabber handles routing and, with ACME configured, requests your certificates.

SYSTEMDsudo systemctl start yabber
OPENWRT/etc/init.d/yabber start

A COMMAND. AND A LIBRARY.

Fits right into
your Go program.

Built on net/http and httputil.ReverseProxy. Embed the gateway, add your own handlers, and reconfigure it through the public API.

Explore the Go API ↗
MAIN.GO
// A gateway, in your program.
config, err := yabber.Load("config.yaml")
if err != nil {
    return err
}
server, err := yabber.New(config,
    yabber.WithDataDir("./data"),
)
if err != nil {
    return err
}
if err := server.Start(); err != nil {
    return err
}
defer server.Close()
